# Licensing — dock

dock is released under the **Apache License 2.0** (`LICENSE`), a permissive licence with an express patent grant. Decision
of the author, 2026-10-05, confirmed 2026-10-09. There are no runtime dependencies, so there is no third-party code to
attribute and no `NOTICE` file.

Other repositories by the same author use other licences (PolyForm Small Business 1.0.0 OR PolyForm Noncommercial 1.0.0
for source-available code that may be sold; CC BY 4.0 for research text; Apache-2.0 for freely usable tools such as dock
and omnid). Each repository states its own licence in its own `LICENSE`. **No code is shared across the licence
boundary**: dock contains no PolyForm code, and a PolyForm repository may use dock only as a separate program.

The behaviour dock is built around — abstaining when nothing is relevant — is protected by public disclosure
(`TECHNICAL-DISCLOSURE.md`), not by licence terms.
